# Dog models

`ShibaInu.glb` and `Husky.glb` are from Quaternius’s **Ultimate Animated Animal Pack**.

- Author: [Quaternius](https://quaternius.com)
- Pack: https://quaternius.com/packs/ultimateanimatedanimals.html
- Shiba Inu on Poly Pizza: https://poly.pizza/m/y4wdQpg767
- Husky on Poly Pizza: https://poly.pizza/m/wcWiuEqwzq
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) (public domain dedication)

The pack page states the models are free to use in personal and commercial projects. CC0 waives copyright, so redistribution in this repo is permitted. Attribution is not required; we still credit Quaternius on `/en/dog/` because the work is worth naming.

Files were copied from the CC0 pack mirror at [trebeljahr/quaternius-showcase](https://github.com/trebeljahr/quaternius-showcase) (`public/glb/animals_pack/`), which documents the same upstream CC0 license.

# Open world map data

Street, building, park, and water geometry on `/en/dog/` is streamed from [OpenFreeMap](https://openfreemap.org) vector tiles (OpenMapTiles schema).

- Map data: © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, ODbL
- Tiles and style schema: © [OpenMapTiles](https://openmaptiles.org/license/)
- Tile hosting: [OpenFreeMap](https://openfreemap.org)

The live HUD shows this credit while Biscuit is in the world. TileJSON is fetched at runtime so dated tile URLs are not hardcoded.
